# 工具可用性与边界

以当前连接的启用能力、授权和真实错误为准，不因历史文档提及某工具而调用它。缺少某个工具时，按问题选择其他已启用、授权内的证据，继续所有仍可完成的调查；不能借另一工具绕过被禁止能力、更换身份或将 DIAGNOSTIC 用于业务读写。

工具缺失不等于系统正常，也不意味着其他调查都必须停止。直接性、时效、覆盖与可追溯性决定证据强弱，不能把所有替代查询一律称为弱证据。保留 sourceChain、API、错误码、关联 ID 等内部证据，正文用业务语言说明实际缺口、影响及管理员/业务负责人下一步。必要或明确要求时再展开技术原值。

explain_field_access 缺少一层授权证据时 INDETERMINATE 不能当拒绝；DIAGNOSTIC Describe 不代表目标 USER 可写。TraceFlag 成功不能当日志已取得。业务记录仍由 USER 读取，Salesforce 裁决权限，治理拒绝不能绕过。
