# 证据引用义务

诊断回答的每一句话，都要能指回一条可以被别人重新读到的证据。这不是文风要求，是**可复核性**要求：用户会拿着你的结论去找我们改配置、改权限、改代码；如果你无法指认是哪一条证据支撑的，那么改错的责任无法定位，结论也无法被推翻。

## 一条「可引用证据」的最低形态

| 结论类型 | 必须能指到 | 典型反例（不合格） |
| --- | --- | --- |
| 配置行为 | 组件 **fullName** +（与时间相关的结论还要）最后修改时间与修改者 + 定义中支撑结论的那一段 | 「应该是校验规则拦的」 |
| 代码异常 | **类名 + 行号** + 异常消息原文 + 触发它的执行标识（时间/执行者/日志条目） | 「有个空指针异常」 |
| 权限 | **授权来源链**：哪条 Profile / 哪个 PermissionSet / 哪条赋值给了权限，以及被什么抵消 | 「用户没权限」 |
| 变更溯源 | **审计条目的时间戳 + 操作者 + 动作**，以及它与异常起点的相对位置 | 「最近有变更」 |
| 数据异常 | **字段 API 名** + 覆盖率（`fetched` 对 `totalSize`、是否 `truncated`）+ 具体记录标识 | 「查了一下确实是空」 |
| 平台状态 | 该节的**状态字面量**（读到 / 不可用 / 不确定）+ 行数或缺失前提 | 「平台没问题」 |

数量不是证据。**一条指到 fullName 的证据胜过十条「看起来相关」的条目。**

## 三档表述：证据 / 推断 / 未知

写结论时把它们分开，不要混成一句自信的话：

- **证据（读到的）**：「校验规则 `X__c` 的 `Active` 为真，且它在 09-30 14:12 被修改过。」——这是 Tool 返回的事实，可以直陈。
- **推断（由证据推出的）**：检验「这条规则能解释这个症状」是否成立。写的时候带上推理过程与前提；前提不成立时结论作废。
- **未知（没有证据的部分）**：明确写出「这部分我没有证据」，以及**差哪一条证据**、**哪个 Tool 能提供它**。写「未知」是合格答案，编一个「大概是因为…」不是。

> 反例：「这个字段不可见是因为权限集的问题。」
> 正例：「`Account.X__c` 对目标用户 `visible: false`；授权来源链显示该字段的可见性只来自简档 `Y`，而该用户的简档是 `Z`，且没有任何权限集为该字段补过可见性——**证据**到此为止。**推断**：若预期是可见，那么缺的是 `Z` 或某个权限集上的字段级权限行。**未知**：这是不是预期行为需要业务确认，我只能说现状与来源，不能替业务判定。」

## 授权来源链要读出来的东西

权限结论最容易被答成一句「没权限」。来源链至少要能回答：

1. **权限从哪里来**：对象级/字段级分别由哪些简档、哪些权限集提供。
2. **有没有互相抵消**：能给的给了、又被另一处限制的情况要指出方向。
3. **是不是「一条行都没有」**：没有可见性行本身就是一种事实，与「有行但值为假」是不同的证据，不要混为一句「不可见」。
4. **结论是解释，不是裁决**：Tool 解释「为什么现在是这样」；「用户最终能做什么」由 Salesforce 在真实请求上裁决。

## 多假设并行时，按证据强度排序

同一症状常有多个候选解释。**不要**并列陈述然后让用户挑——排序是诊断者的工作。强度从高到低：

1. **指名证据**：能落到组件 fullName / 日志行号 / 审计条目时间戳上的。
2. **类别证据**：能证明「这一类里存在某个东西」但还没指名的（例如某类型下有若干组件、其中若干近期被改过）。
3. **时间相关性**：只在时间上接近，语义上还没建立联系。
4. **结构性推断**：只凭「这种配置通常是这样的」。

规则：

- 先验证第 1 档。它一旦成立，后面几档就不必再猜。
- 第 3 档 **MUST** 被显式标注为**相关**，并写出「还差哪一条证据」才能升级成因果（通常是：该条目的语义正好能解释症状）。
- 第 4 档 **MUST NOT** 作为结论出现，只能作为「接下来去读什么」的路由。

## 引用时的取舍

- **引用必要的那一段**，不要把整个组件定义或整条日志贴进回答。引用是为了让结论可复核，不是为了展示读过的东西。
- **保留 Tool 自己的错误码与标识**（错误码、相关 ID）。它们是用户找我们复核时的钥匙；改写成自然语言会让复核断线。
- **时间要带时区或明确基准**。来自不同来源的时间戳可能不属于同一个时钟域，见 [time-alignment.md](time-alignment.md)。
- **不要引用与被诊断对象无关的字段值**。诊断回答进入业务对话，业务敏感值能省则省；确需引用记录时用内部标识，不展开无关字段。
