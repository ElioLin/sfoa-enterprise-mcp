# Phone and Mobile

用于 CREATE/UPDATE 前把用户给出的号码分类到 `Phone`（电话/座机）或 `MobilePhone`（手机），并按中国大陆规则校验。

## 1. 字段识别

- 先看当前对象 / Record Type 的 action context 字段：`label`、`apiName`、`dataType`、`inlineHelpText`。
- 手机候选：label / apiName 含「手机」「移动电话」「Mobile」「MobilePhone」「Cell」。
- 电话候选：label / apiName 含「电话」「联系电话」「座机」「固定电话」「办公电话」「Phone」「Tel」「Telephone」。
- **MUST NOT** 凭历史对象或模型记忆硬编码字段 API 名；只使用当前 context 返回的字段。

## 2. 分类规则

按以下优先级：

1. 用户明确说「手机 / 移动电话」→ 手机字段；明确说「座机 / 固定电话 / 办公电话」→ 电话字段。
2. 用户只说「电话 / 联系电话」或未指定 → 按值的格式判断：
   - 去掉空格、连字符、括号、`+86` / `86` 国家码后，匹配 `^1[3-9]\d{9}$` → 手机字段；
   - 匹配 `0\d{2,3}` 区号 + 7-8 位本地号码（可带分机）→ 电话字段；
   - 两种都不匹配，或位数不足 / 超长 / 含字母 → `INVALID` / `AMBIGUOUS`，先询问。
3. 显式标签与格式冲突（例如用户说「手机」但值是 `0592-8888888`）：**MUST NOT** 静默换字段；先问。
4. 同一号码 **MUST NOT** 同时写入 Phone 和 MobilePhone，除非用户明确要求。

## 3. 中国大陆规则

### 手机

- 本地号码 11 位，`1` 开头，第二位 `3-9`：`^1[3-9]\d{9}$`。
- 可带 `+86` 或 `86` 国家码；校验前去掉。
- 允许空格 / 连字符分隔；校验前去掉。
- 10 位、12 位、第二位 `0-2`、含字母或其他明显格式 → 无效，插入前询问。
- 例：`13800138000`、`+86 138-0013-8000` 有效；`123456789096`（12 位）、`12345678901`（第二位 2）、`1380013800`（10 位）无效。

### 电话 / 座机

- 区号 `0\d{2,3}`（如 `010`、`021`、`0592`、`0755`）+ 7-8 位本地号码，可带 `-` / 空格。
- 可带分机：`-1234`、`转1234`。
- 可带 `+86`；注意北京等区号在 `+86` 后可省略前导 0（例如 `+86-10-12345678`）。
- 位数明显不足、含字母、无区号且无法判断 → 询问。
- 例：`0592-8888888`、`010-12345678`、`+86-10-12345678` 有效；`12345`、`0592-888` 位数不足 → 询问。

## 4. 插入前行为

- 校验失败或存在歧义：**MUST NOT** 调用 `create_record` / `create_records` / `update_record` / `update_records`；先给用户一条简短提示，说明原因并请其确认或更正。
- 提示示例：
  - 手机：`您提供的手机号 123456789096 是 12 位；中国大陆手机号通常为 11 位（可带 +86，1 开头，第二位 3-9）。请确认是手机号还是电话，或更正后我再写入。`
  - 电话：`您提供的电话 12345 位数不足/格式不完整，请补充区号或确认。`
- 用户明确确认「就按这个存」后，可以按原值写入，并在结果中说明它是非标准格式；**MUST NOT** 截断、补位、编造数字或擅自改字段。
- 正常值：按识别出的字段写入；如需去掉分隔符 / 国家码，说明规范化；不改变用户数字。

## 5. 与其他规则的关系

- 号码是显式事实，受 `Explicit Fact Coverage` 约束：**MUST NOT** 只写进 Description。
- 号码字段可能是必填；缺失时按 requiredness source 追问。
- 查重：CREATE 前和 UPDATE 引入新号码时，按 [duplicate-check.md](duplicate-check.md) 对 Phone / MobilePhone / Email 等身份键做有界查重并提示用户；0 行只说明当前共享范围未发现，不证明全库无重复。

## 6. 号码与地域推断

- 座机区号、明确地址或公司所在地等可靠证据能确定城市时，**MUST** 同时推断并写入对应的省份和国家（当前字段可写且不与现有值冲突时），不得只填城市把省份留空。
- 例：`0592` → 厦门市 → 福建省 → 中国；`0571` → 杭州市 → 浙江省；`0755` → 深圳市 → 广东省；`010` → 北京市；`021` → 上海市。
- 手机号本身不含地域信息，**MUST NOT** 用手机号段推断城市/省份。
- 区号与城市不是一一对应、或地名重名/跨省歧义时，先询问；不得猜。
- 与现有国家/省份冲突时，先按 [SKILL.md](../SKILL.md) 的地域冲突规则核对地点角色与意图，不得直接覆盖。
