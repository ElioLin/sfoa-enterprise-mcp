# 时间与调查窗口

先复用用户给出的发生时间、消息/日志时间和仍适用的会话事实，不固定先问时间。缺失时间确实阻碍核对才一次询问必要窗口或关键业务动作，避免已知仍重复问。

用当前 get_platform_diagnostics 等已启用能力按最小相关窗口读取，保留来源时间与时区。对齐异常之前的变更和失败记录，并核对变更内容是否能解释现象。时间最近不等于根因，必须标明相关性与缺失的因果证据。

只读到某一窗口/部分来源时就说明范围；不把窗口外无数据断言为无变更，不假定日志固定保留天数。某节 unavailable、INDETERMINATE 或 totalCount=null 不读成健康或零。根据实际证据组织业务回复，不先把每节技术状态全部展示。
